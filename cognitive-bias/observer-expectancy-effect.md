# 观察者期望效应


[观察者期望效应](https://zh.wikipedia.org/wiki/%E8%A7%80%E5%AF%9F%E8%80%85%E6%9C%9F%E6%9C%9B%E6%95%88%E6%87%89) 在科学实验中，由于观察者预期某些测试结果，于是无意识地以某种形式操纵了实验步骤，或错误解释实验结果以达至他们希望得到的结论。观察者期望效应能严重歪曲实验结果，因此需利用双盲方式进行实验来消除这效应。
由于研究者期待某种结果，因而下意识中不适当地操作实验或诠释资料（参见[[subject-expectancy-effect|受试者期望效应]]）。
