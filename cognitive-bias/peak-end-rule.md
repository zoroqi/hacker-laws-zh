# 峰终法则

[峰終定律](https://zh.wikipedia.org/wiki/%E5%B3%B0%E7%B5%82%E5%AE%9A%E5%BE%8B) 指人们对某段经历的整体评价，主要会基于其在“高峰”（体验中最强烈的时刻）与“结尾”时的感受强度，而非对每个时刻的总和或平均评估。无论该体验是愉悦或痛苦，此效应皆成立。根据此法则，除了高峰与结尾的资讯外，其他因素（如整体愉悦程度、持续时间长短）虽未被遗忘，却不会被纳入评估。
